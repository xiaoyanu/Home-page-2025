# 简介
这是一个开源的个人主页，距离上一次编写个人主页已经是在几年前了，也是时候推出自己的新的个人主页了！本次不同以往，采用的是高斯模糊化为主的风格，整体分为为三个部分，相对来说比之前的更加简洁，同时利用js来实现随机的盲盒作品展示，增加了作品的展示空间上限问题。
